

PRIMITIVE TYPES

  Primitive types are passed by value.
  Primitive types are not objects.

  Boolean, character types
  boolean
  char

  Integer types
  byte
  short
  int
  long

  Floating point types
  float
  double


ARRAYS

  Arrays can store primitive or reference types.
    ChessPiece[][] chessBoard;
    chessBoard = new ChessPiece[8][8];


COLLECTIONS

  Collection<Integer> example = new ArrayList<>();

  Containers are designed to hold objects, e.g. Integer.
  They offer greater flexibility in manipulation.
  Collections and arrays can be converted interchangeably.
  
    String [] myStrings = { "a", "b", "c" };
    List list = Arrays.asList(myStrings);

    Collection<String> myCollection = ...;
    String [] myStrings = myCollection.toArray(new String[0]);

  The shared superclass is Collection, which features:
    add(obj)
    remove(obj)
    contains(obj)
    size()
    iterator() -> Iterator obj returned

  There are interfaces and implementations...
    For example, ArrayList is one implementation of List.
    An interface is a set of empty methods, which an implementation may fulfill the functionality of.
    Subinterfaces may provide 

  Casting
    Data stored within types with some inheritance relationship can be cast to subtypes.

  Map<String, Date> dateMap = new HashMap<String, Date>();
  dictionary.put("today", new Date());

CLASS SYNTAX

  Objects are pass-by-reference.

  Inheritence
  ... extends Superclass_name {}

  Public/private
  'public' allows methods to be called by methods outside of the class.
  'private' variables and methods can only be called from within class, classes can only be package-private.

  Static
  'static' variables and methods shared by all instances of class (only one variable value can exist at a time)
  This allows for functional programing, e.g. by filling a class with static functions (however, watch out for Java's pass-by-reference)

  Final
  'final' is short for final declaration, as in constant.

  Enhanced for-loop
  for(int i  : arrayOfInts) {
    System.out.println(i);
    total = total + i;
  }

  main()
  At least one class is to contain main()
  public static void main(String [] args) {}
  This means, the method can be called from outside the class, the method does not belong to the objects, return nothing, arguments as string.

  Constructors
  Method names that are equivalent to the class name, multiple methods may take different argument lists.
  The constructor is to return nothing, else it is bypassed.
